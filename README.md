## Project Setup

```sh
npm install
```

## Run modes
### Run web dev
```npm run web```
### Run electron build in dev mode
```npm run electron```
### Build web ver
```npm run build-web```
### Build electron ver
```npm run build-electron```
### Build standalone Windows electron ver with installer
```sh
npm run build:win
```

### Build 32-bit standalone Windows electron ver with installer
```sh
npm run build:win32
```
